# PROGRAMA DE GESTION DE PRODUCTOS BASICO

## SQLite integrado con Python

## Funciones:
 
- Agregar productos.
- Mostrar productos de forma completa o resumida.
- Actualizar información de productos.
- Busqueda de productos mediante ID, nombre o categoria.
- Eliminar productos.
- Reporte de productos segun stock minimo.
- Vaciar tabla

### Uso: correr el archivo main.py e interactuar con el menu por consola.
